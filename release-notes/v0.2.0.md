🎮 **Steam Auto Status v0.2.0** — the settings update!

Same lightweight tray app that keeps your Steam presence in sync with your schedule — now with a full settings panel, your account up front and the app version always in sight. 🎛️

## ✨ What's new

- 🧭 **Dashboard + Settings** — the panel now has two sections, one click apart: live status on the dashboard and everything configurable in settings.
- ⚙️ **Full settings module**, with five sections:
  - 🕒 **Schedule** — Online window (from/until) and weekdays, with a readable summary and one-click restore to defaults.
  - 👤 **Account** — connected session and SteamID, machine name, reconnect, and log out (deletes the stored token).
  - 🖥️ **App** — start with Windows (launches minimized to the tray) and Windows notifications on state changes.
  - 📂 **Data** — open the data folder, copy a support diagnostics report (version, connection state, recent log) and clear the log.
  - ℹ️ **About** — version and links to the repository, the latest release and the issue tracker.
- 🖼️ **Account header** — avatar and name now sit in the panel header, with a live status dot. The avatar is fetched from Steam, cached locally and refreshed automatically.
- 🏷️ **Version, always visible** — header badge and About show the exact version of the installed build.
- 🇬🇧 **English for developers** — code comments and developer-facing messages are now written in English.
- 📜 **GPL-3.0** — the project is now formally open source.
- 📖 **New README** — a user-first guide: what it is, how to install it and how to use it.

## 🔄 Updating from v0.1.0

Run the new installer on top of the old version — your config, token and logs in `Documents\steam-auto-status\` are preserved, and no re-login is needed.

## 📥 Installation

1. Download **[steam-auto-status_0.2.0_x64-setup.exe](https://github.com/Juankyyy/steam-auto-status/releases/download/v0.2.0/steam-auto-status_0.2.0_x64-setup.exe)** and run it — per-user install, no admin rights, available in English & Spanish.
2. Windows may warn about an unknown publisher (the app isn't code-signed): **More info → Run anyway**.
3. It lives in the system tray (next to the clock): click the icon to open the panel.

## 🔐 Your data

- Config, token, logs and the avatar cache live in `Documents\steam-auto-status\` (not AppData) and **survive reinstalls and uninstalls**.

## ✅ Requirements

- Windows 10/11 (x64). WebView2 ships with Windows 10/11; the installer only downloads it if missing.
