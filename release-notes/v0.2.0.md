<!-- title: v0.2.0 - The Settings Update -->

Same lightweight tray app that keeps your Steam presence in sync with your schedule — now featuring a full settings panel, your account up front and the app version always in sight.

## ⚙️ Settings module

The panel now has two sections, one click apart: live status on the dashboard and everything configurable in settings.

- **Schedule**: Online window (from/until) and weekdays, with a readable summary and one-click restore to defaults.
- **Account**: connected session and SteamID, machine name, reconnect, and log out (deletes the stored token).
- **App**: start with Windows (launches minimized to the tray) and Windows notifications on state changes.
- **Data**: open the data folder, copy a support diagnostics report (version, connection state, recent log) and clear the log.
- **About**: version and links to the repository, the latest release and the issue tracker.

## ✨ What's new

- **Account header**: avatar and name now sit in the panel header, with a live status dot. The avatar is fetched from Steam, cached locally and refreshed automatically.
- **Version, always visible**: header badge and About show the exact version of the installed build.
- **English for developers**: code comments and developer-facing messages are now written in English.
- **GPL-3.0**: the project is now formally open source.
- **New README**: a user-first guide: what it is, how to install it and how to use it.
